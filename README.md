
# StreamFlix – Content Analytics Project

## 📌 Project Overview
StreamFlix is a content analytics project focused on understanding streaming platform performance, audience preferences, and content engagement. The project aims to explore viewing patterns, analyze content performance, and identify useful insights from streaming data.

## 🎯 Project Objectives
- Analyze movies and TV shows available on the platform.
- Understand audience viewing preferences.
- Identify popular content and genres.
- Analyze content ratings and viewer engagement.
- Track important performance indicators.
- Present insights through interactive dashboards.

## 🛠️ Tools & Technologies
- **Power BI:** Interactive dashboard development and data visualization.
- **Excel:** Data organization and analysis.
- **Python:** Data analysis and data cleaning.
- **Jupyter Notebook:** Data exploration and analysis.

## 📊 Project Analysis
- Explored streaming content and viewing data.
- Analyzed content categories, genres, and ratings.
- Identified patterns in audience preferences.
- Evaluated content performance using key metrics.
- Created visualizations to present analytical findings.

## 📈 Key Deliverables
- Data analysis and exploration.
- Content performance analysis.
- Audience preference insights.
- Key Performance Indicators (KPIs).
- Interactive Power BI dashboard.
